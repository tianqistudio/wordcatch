# 单词捕手 · WordCatch 0.5.0

安装包内置运行环境、本地 OCR 模型和英汉词典。安装后从快捷方式打开，无需另装 Python 或 .NET。

## 使用

先用鼠标选择文字，再按 Ctrl + Alt + D。支持系统选区接口的软件优先读取选中的文字；没有选区、无法读取或接口超时时，识别鼠标下的单词。

同一次快捷键查询也会读取剪贴板文字，在独立词卡显示；两路结果可分别编辑和重查。剪贴板为空或不含文字时只显示屏幕结果；被占用或超过 2,000 字符时提示重试，不影响屏幕取词。窗口较窄时两张词卡上下排列，可滚动查看。程序不后台监听剪贴板，取词不改写剪贴板，只有点击「复制原文」才会写入剪贴板。

完整词未收录时，会尝试按连字符、下划线或驼峰边界拆分。例如 `response-conventions` 分别查询 `response` 和 `conventions`，未收录的部分单独标注。已收录的完整词优先保留；普通句子仍使用整句翻译，拆分释义不代表整词或整句的译文。

## 本地词典

本地词典包含 770,611 词条，其中 768,739 条有中文释义。它包含单词、短语、专名和变形，不等于 77 万个独立基础单词；不提供离线整句机器翻译。

## Azure 云端备用

1. 打开主窗口的「设置与关于」。
2. 从自己的 Azure Translator 资源获取密钥与区域（例如 eastasia）。全球单服务资源可按 Azure 资源要求留空区域。
3. 填写后可点击「测试连接」；仅发送固定测试词 Hello。
4. 勾选「启用云端备用翻译」并保存。

启用后，无法提供本地词条或拆分释义时，可使用云端备用翻译；已收录但无中文释义的词条也会尝试云端。也可点击词卡的「云端翻译」主动翻译。每次最多 2000 字符。截图不上传，密钥仅使用 Windows 当前用户 DPAPI 加密保存；其他 Windows 账户无法直接使用该密钥文件。

Azure 需要用户自备有效订阅，计费与额度以 Azure 账户为准。程序不创建账户、购买服务或包含共享密钥。断网、密钥无效、限额及超时会显示明确错误，本地词典可继续使用。

## 安装与退出

安装器默认创建桌面、开始菜单两个快捷方式，可独立取消；再次安装沿用选择。开始菜单分组为 tianqistudio。安装不会自动开启开机自启动。

关闭主窗口会收起到通知区域，退出请使用主窗口或通知区域菜单「退出」。安装和卸载前须退出所有单词捕手实例。安装器使用独立版本目录，成功后更新快捷方式；旧版本保留到卸载时按清单移除。同版本允许重新安装，降级拒绝。

卸载只移除清单登记且未被修改的程序文件；未知文件不递归删除。快捷键和云端配置保留在 `%LOCALAPPDATA%\TianqiStudio\WordLens`。失败的安装暂存目录可能保留供排查，不视为成功版本。

当前安装包未数字签名。

新版采用猫爪与 W 平面图标。主窗口集中输入与快捷键，词卡保留取词来源；长句采用较小原文字号和独立译文区域。设置页可查看词库数量。安装时会将本程序旧名快捷方式替换为「单词捕手」，原安装和用户配置路径保持兼容。

## 检测更新

默认开启自动检测，每 6 小时最多一次；启动后在后台检查，常驻时定期检查，不上传查询内容。可在「设置与关于」关闭自动检查，选择自动、tianqistudio.com 或 GitHub，也可随时手动检查。自动模式比较两源版本，单源失败时使用另一源。发现新版本后显示通知与入口；点击打开 GitHub 发布页，自行下载安装。本程序不会自动下载、执行或静默升级。网站仅托管版本清单，安装包托管在 GitHub Releases。

## 开机自启动

在「设置与关于」勾选「开机自启动」并保存。默认关闭，仅对当前 Windows 用户生效；登录后收起到通知区域，仍可使用取词快捷键。取消勾选并保存即可关闭。升级会保留安装账户的开关并更新启动路径；卸载会移除该账户的启动项。其他 Windows 账户需分别管理其启动设置。

## 个人短语库

程序可从当前 Windows 用户的 `%LOCALAPPDATA%/TianqiStudio/WordLens/anki-phrases.sqlite3` 读取已整理的 Anki 短语库。完整输入、选区和剪贴板优先匹配短语；鼠标取词可在同一行相邻文字中匹配包含鼠标位置的最长短语，未命中时回退单词查询。释义标明 Anki 来源；只有名称而没有释义的记录不会编造翻译。

个人短语库不随安装包分发，也不会由安装程序抓取 Anki 数据。没有该文件时继续使用原有词典。

## 框选翻译

按 Ctrl + Shift + Alt + D，在屏幕上拖出矩形，松开鼠标识别框内文字；Esc 或右键取消。支持反向拖动，截图仅在内存中处理。识别结果保留换行。启用云端备用翻译后直接翻译整段文字；未启用时显示原文与可用的本地释义。超过 2,000 字符需缩小选区。主窗口显示快捷键注册冲突。
